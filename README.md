# Sales Insights Dashboard

## Project Overview
This project analyzes sales performance data using SQL and Power BI.

The dashboard provides insights into:
- Revenue Performance
- Sales Quantity Analysis
- Market-wise Revenue Distribution
- Revenue Trends
- Top Customers
- Top Products

## Tools Used
- SQL
- Power BI
- DAX

## Key Metrics
- Revenue: ₹984.81M
- Sales Quantity: 2M

## Dashboard Features
- Revenue by Market
- Sales Quantity by Market
- Revenue Trend Analysis
- Top 5 Products
- Top 5 Customers
- Year and Month Filters

## Business Insights
- Delhi NCR contributes the highest revenue.
- Revenue shows a declining trend after 2019.
- A small number of customers contribute a significant portion of total revenue.
- Product performance is highly concentrated among top products.
